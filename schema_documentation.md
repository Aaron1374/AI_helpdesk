# Database Schema Documentation

This document provides a comprehensive overview of all the database schemas, tables, and enums used in the AI Helpdesk application. It maps directly to the underlying PostgreSQL + `pgvector` database.

---

## Enums and Types

The application relies heavily on strict enumerations to maintain data integrity across states, ownership, and permissions.

### `UserRole`
Defines the permission level and dashboard access for a user.
- `employee`: Standard user, can only view and interact with their own tickets.
- `l1`: Level 1 Support Engineer.
- `l2`: Level 2 Support Engineer.
- `support_lead`: Support manager with oversight.
- `admin`: System administrator.

### `TicketStatus`
Tracks the lifecycle of a support ticket.
- `NEW`: Ticket just created.
- `TRIAGED`: Categorized and prioritized by AI or human.
- `IN_PROGRESS`: Actively being worked on by an engineer.
- `RESOLVED`: Solution provided, awaiting user confirmation.
- `CLOSED`: Confirmed resolved and finalized.
- `ESCALATED`: Escaped L1/AI scope, requires human intervention.

### `ConversationOwner`
Indicates who currently "owns" the conversation thread.
- `AI`: The LangGraph Agent is actively talking to the user.
- `HUMAN`: An engineer has taken over the chat.

### `ConversationStatus`
- `ACTIVE`: Chat is open.
- `CLOSED`: Chat has concluded.

### `SenderType`
Identifies the source of a message inside a conversation.
- `USER`: The employee.
- `AI`: The conversational agent.
- `SYSTEM`: Internal logs or status updates (e.g., "Ticket Escalated").

## Core Entities (Tables)

### 1. `users`
Stores all personnel accessing the system.

| Field | Type | Attributes | Description |
| :--- | :--- | :--- | :--- |
| `id` | `UUID` | Primary Key | Unique identifier. |
| `name` | `String` | Not Null | User's full name. |
| `email` | `String` | Unique, Indexed, Not Null | User's email address. |
| `hashed_password`| `String` | Not Null | Securely hashed credential. |
| `role` | `Enum(UserRole)` | Not Null, Default: `employee`| Access level. |
| `department` | `String` | Nullable | Employee's business unit. |

### 2. `conversations`
Represents a chat thread between a user and the AI (or an engineer).

| Field | Type | Attributes | Description |
| :--- | :--- | :--- | :--- |
| `id` | `UUID` | Primary Key | Unique identifier. |
| `user_id` | `UUID` | Foreign Key (`users.id`) | The employee who started the chat. |
| `owner_type` | `Enum(ConversationOwner)`| Default: `AI` | Who is currently responding. |
| `status` | `Enum(ConversationStatus)`| Default: `ACTIVE` | Whether the chat is still ongoing. |
| `created_at` | `DateTime` | Default: `utcnow` | Timestamp of creation. |
| `updated_at` | `DateTime` | Default: `utcnow`, OnUpdate | Timestamp of last activity. |

### 3. `messages`
Individual chat messages inside a conversation.

| Field | Type | Attributes | Description |
| :--- | :--- | :--- | :--- |
| `id` | `UUID` | Primary Key | Unique identifier. |
| `conversation_id`| `UUID` | Foreign Key (`conversations.id`)| Parent conversation thread. |
| `sender_type` | `Enum(SenderType)` | Not Null | Who sent the message. |
| `content` | `String` | Not Null | The actual message text. |
| `trace_id` | `String` | Nullable | LangSmith/Observability trace ID. |
| `created_at` | `DateTime` | Default: `utcnow` | Timestamp of message. |

### 4. `tickets`
Structured representation of an IT issue, either auto-generated by the AI or manually created.

| Field | Type | Attributes | Description |
| :--- | :--- | :--- | :--- |
| `id` | `UUID` | Primary Key | Unique identifier. |
| `user_id` | `UUID` | Foreign Key (`users.id`) | The employee who owns the ticket. |
| `conversation_id`| `UUID` | Foreign Key (`conversations.id`)| Link to the context chat. |
| `status` | `Enum(TicketStatus)` | Default: `NEW` | Current state in lifecycle. |
| `category` | `String` | Nullable | e.g., Network, Hardware, Access. |
| `title` | `String` | Not Null | Short summary of the issue. |
| `description` | `String` | Not Null | Full details/symptoms. |
| `embedding` | `Vector(1536)` | Nullable | Vector mapping for semantic search. |
| `department` | `String` | Nullable | Routing department. |
| `created_at` | `DateTime` | Default: `utcnow` | Timestamp of creation. |
| `updated_at` | `DateTime` | Default: `utcnow`, OnUpdate | Timestamp of last activity. |

### 5. `ticket_history`
Tracks all state changes to tickets over time.

| Field | Type | Attributes | Description |
| :--- | :--- | :--- | :--- |
| `id` | `UUID` | Primary Key | Unique identifier. |
| `ticket_id` | `UUID` | Foreign Key (`tickets.id`) | The ticket being tracked. |
| `old_status` | `Enum(TicketStatus)` | Nullable | Previous state. |
| `new_status` | `Enum(TicketStatus)` | Not Null | New applied state. |
| `changed_by` | `String` | Nullable | User ID (None = System/AI). |
| `changed_at` | `DateTime` | Default: `utcnow` | Timestamp of change. |

### 6. `audit_events`
Security and observability log for privileged actions.

| Field | Type | Attributes | Description |
| :--- | :--- | :--- | :--- |
| `id` | `UUID` | Primary Key | Unique identifier. |
| `trace_id` | `String` | Indexed, Not Null | Link to distributed trace. |
| `action` | `String` | Not Null | What happened (e.g., "ESCALATE"). |
| `entity_type` | `String` | Not Null | e.g., "TICKET", "TOOL". |
| `entity_id` | `String` | Not Null | ID of the entity affected. |
| `actor` | `String` | Not Null | Who performed the action. |
| `details` | `JSONB` | Nullable | Payload with extra context. |
| `created_at` | `DateTime` | Default: `utcnow` | Timestamp of event. |

### 7. `knowledge_documents`
The Knowledge Base (RAG) entries populated via `pgvector`.

| Field | Type | Attributes | Description |
| :--- | :--- | :--- | :--- |
| `id` | `UUID` | Primary Key | Unique identifier. |
| `title` | `String` | Not Null | Title of the KB article. |
| `content` | `String` | Not Null | Full text content of the article. |
| `embedding` | `Vector(3072)` | Nullable | High-dimensional vector map (Gemini). |
| `metadata` | `JSONB` | Nullable | Tags, severity, ACLs. |
| `department` | `String` | Nullable | Department restriction. |
| `created_at` | `DateTime` | Default: `utcnow` | Timestamp of creation. |
| `updated_at` | `DateTime` | Default: `utcnow`, OnUpdate | Timestamp of last activity. |
